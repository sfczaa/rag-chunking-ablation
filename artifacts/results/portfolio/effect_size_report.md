# Effect-size & power analysis — "size dominates, method ties"

Derived from the archived Stage 6 dense grid (`stage6_large_eval_results.csv`, 30 `bge` configs = 3 methods x 5 sizes x 2 overlaps, n=1032 questions). No experiment was rerun.

## (a) OLS effect sizes — `R@5 ~ size + overlap + C(method)`

Model R^2 = 0.935. Pearson r(size, R@5) = 0.954 (r(avg_chunk_size, R@5) = 0.951).

| term | coef | 95% CI | t | p |
|---|---|---|---|---|
| intercept | +0.7634 | [+0.7544, +0.7723] | +166.91 | 1.3e-39 |
| size | +0.0071 | [+0.0064, +0.0079] | +18.64 | 3.5e-16 |
| overlap | -0.0064 | [-0.0111, -0.0017] | -2.67 | 0.013 |
| method[bilstm] | +0.0005 | [-0.0053, +0.0062] | +0.16 | 0.87 |
| method[transformer] | -0.0036 | [-0.0093, +0.0021] | -1.23 | 0.23 |

- **Size** moves R@5 by **+0.064** across the swept range (6→15 sentences) and is highly significant (p = 3.5e-16).
- **Overlap** (a nuisance knob) shifts R@5 by -0.0064 per sentence; the size range effect is ~10.1x it.
- **Method** dummies (BiLSTM, Transformer vs fixed) are the smallest terms: max |coef| = 0.0036, p = 0.23–0.87 (not significant). The size range effect is ~**18x** the largest method effect.

## (b) Minimum detectable effect (why the tie is real, not underpowered)

At n = 1032 questions and mean R@5 = 0.832, the unpaired SE of a between-method difference is 0.0165. So this study could:

- call a gap **significant** (95%, two-sided) only if it exceeds **0.032**;
- **detect** a true gap with 80% power only if it is at least **0.046**.

The **largest** between-method R@5 gap at ANY matched (size, overlap) cell is **0.023** — below both thresholds. The tie is therefore consistent with no true method difference, not with an effect too small to have been measured.
